# Contributing

Thanks for improving this list.

## Submission Requirements

- Every submission must include a public `github.com` repository URL.
- No proprietary SaaS products, cloud-only services, affiliate links, or closed-source tools.
- The repo must be relevant to video editors, not just a generic AI project.
- Include the tool's primary language, license, GitHub stars, and a recent GitHub activity date.
- If a tool is research-only, note that clearly.
- If a category has fewer than 5 strong repos, document the gap instead of adding weak entries.

## Pull Request Format

Please include:

1. Repository name and GitHub URL.
2. One short paragraph explaining what the tool does for video editors.
3. License type from GitHub.
4. Primary language from GitHub.
5. Star count snapshot from GitHub.
6. Last commit or latest visible GitHub activity date.
7. Suggested category.

## Editorial Standard

- Favor practical, maintained repositories over hype.
- Prefer repos with clear README documentation.
- Remove entries that become unavailable, closed-source, or irrelevant.
- Keep descriptions specific and avoid generic marketing language.

## Local Check

Before submitting, make sure:

- `README.md` still renders cleanly.
- Every tool links to `github.com`.
- The list remains focused on open source AI tools for video editors.
